## 1. 개요

> **일반 CMS가 아닌, 연구/실험 플랫폼**

관리자 페이지는 학습 서비스의 **실험 설계 → 배포 → 측정 → 분석** 사이클을 지원하는 연구 플랫폼입니다.

### 1.1 핵심 원칙

- **가설 기반**: 모든 기능 변경은 가설과 실험을 통해 검증
- **데이터 중심**: A/B 테스트와 분석을 통한 의사결정
- **실시간 반영**: Feature Flags로 즉시 변수 조정 가능

## 3. 🧪 실험실 (Lab)

### 3.1 실험 관리

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 실험 목록 | 진행중/완료/보류 실험 조회 | P0 (MVP) |
| 실험 생성 | 가설, 변수, 코호트, 성공 지표 설정 | P1 |
| 실험 배포 | 활성화/비활성화 | P1 |
| 분석 대시보드 | 결과 통계, 세그먼트 분석 | P1 |

### 3.2 변수 관리 (Feature Flags)

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 변수 목록 | 학습 테마별 변수 조회 | P0 (MVP) |
| 변수 편집 | control/treatment 값 설정 | P0 (MVP) |
| 실시간 적용 | 앱 재배포 없이 즉시 반영 | P0 (MVP) |

### 3.3 AI 프롬프트 관리

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 프롬프트 편집 | 시스템 프롬프트 작성/수정 | P0 (MVP) |
| 버전 히스토리 | 프롬프트 변경 이력 | P1 |
| 테스트 콘솔 | 프롬프트 테스트 실행 | P0 (MVP) |
| 모델/파라미터 | Temperature, Max Tokens 설정 | P1 |

## 7. 기술 스택

| 카테고리 | 기술 | 이유 |
|----------|------|------|
| 프레임워크 | Next.js 15 (App Router) | 모바일 앱과 React 생태계 통일 |
| UI | shadcn/ui + Tailwind | 모바일과 동일한 디자인 시스템 |
| 상태 관리 | Zustand | 가볍고 직관적 |
| API 통신 | React Query (TanStack Query) | 서버 상태 캐싱, 자동 갱신 |
| 폼 | React Hook Form + Zod | 타입 안전 폼 검증 |
| 테이블 | TanStack Table | 정렬, 필터, 페이지네이션 |
| JSON 에디터 | Monaco Editor | VS Code 같은 편집 경험 |
| 차트 | Recharts | 분석 대시보드용 |

## 8. MVP 우선순위

1. **변수 관리** - 학습 테마별 Feature Flags
2. **AI 프롬프트 관리** - 프롬프트 에디터 + 테스트
3. **시나리오 에디터** - 기본 CRUD
4. **로그 수집** - 사용자 행동 로그
