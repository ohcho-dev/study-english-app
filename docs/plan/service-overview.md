## 📋 사용자 요청 (User Request)

> 1. 비즈니스 모델은 구독으로 생각중이야. 하지만 아직 mvp 단계이기 때문에 고려는 하되 포함하지 않고 개발을 해야 해.
> 2. 타겟 사용자는 대학생과 직장인이 목표야
> 3. 시나리오 부분은 아직 신경쓰지 마. 기능 구현을 우선적으로 하고 추후 시나리오 관련 개발을 할 때 다시 얘기하자.
> 4. 온보딩 플로우는 너가 기획을 해주면 좋겠어. 로그인/회원가입 로직은 SSO(카카오/네이버/구글)로 하도록 진행해줘.
> 5. 레벨/진도 시스템은 어떤식으로 관리해야 할지 여러 영어회화 서비스를 벤치마킹 한 후 기획이 필요해.
> 6. 데이터 스키마는 너가 그려줘.
> 7. 아마도 관리자페이지도 필요할 거야. 관리자페이지 구성도 생각해주어야해.

## 📝 서비스 정리

### 1. 서비스명
**AI 영어 회화 서비스** (1:1 시뮬레이션 & 그룹 교실)

### 2. 핵심 가치
- **몰입형 학습**: 실사 배경 영상 + AI 음성 대화
- **실시간 피드백**: 의도 기반 채점 + 3-Mood 표현 추천
- **그룹 학습**: AI 학생들과 함께하는 순차 발언 교실

### 3. 타겟 사용자
| 그룹 | 특성 | 니즈 |
|------|------|------|
| **대학생** | 취업 준비, 교환학생 | 실전 회화, 토익스피킹 대비 |
| **직장인** | 비즈니스 영어 필요 | 회의/발표/이메일 영어 |

### 4. 비즈니스 모델
- **최종 모델**: 구독 (Subscription)
- **MVP 단계**: 결제 기능 제외, 핵심 기능 검증 우선

### 5. 핵심 기능 (MVP Scope)

| 기능 | 설명 | MVP 포함 |
|------|------|---------|
| 소셜 로그인 | 카카오/네이버/구글 SSO | ✅ |
| 1:1 시뮬레이션 | 상황별 미션 수행, 배경 전환 | ✅ |
| 그룹 교실 | 6인 순차 발언, AI 평가 | ✅ |
| 레벨/진도 시스템 | 학습 진척도 관리 | ✅ (벤치마킹 후 기획) |
| 관리자 페이지 | 운영 도구 | ✅ |
| 구독 결제 | PortOne 연동 | ❌ (MVP 이후) |
