# AI Lab 테스트 파이프라인 가이드

## 개요
이 문서는 AI Lab의 주요 기능을 테스트하기 위한 파이프라인 설정 가이드입니다.

---

## 1. TTS 테스트 파이프라인 🔊

**목적**: 텍스트 입력 → AI 응답 → 음성 생성

### 파이프라인 설정
- **이름**: `TTS 테스트`
- **설명**: 응답을 음성으로 생성하는 테스트

### 에이전트 구성
| 순서 | 역할 | 프롬프트 |
|------|------|----------|
| 1 | 영어 선생님 | `학생의 질문에 친절하게 영어로 답변해주세요. 2-3문장으로 간결하게 답변하세요.` |

### 실험 설정
- **모델**: `gemini-2.5-flash` (추천)
- **결과 음성 생성**: ✅ 체크
- **음성**: Kore (여성) 또는 Puck (남성)

### 테스트 입력 예시
```
What's the difference between "affect" and "effect"?
```

---

## 2. 오디오 입력 테스트 파이프라인 🎙️

**목적**: 녹음 파일 → 음성 분석 → 피드백

### 파이프라인 설정
- **이름**: `발화 분석 테스트`
- **설명**: 학습자 발화 녹음을 분석

### 에이전트 구성
| 순서 | 역할 | 프롬프트 |
|------|------|----------|
| 1 | 발음 코치 | `학생이 녹음한 오디오를 분석해주세요. 발음, 억양, 유창성을 평가하고 개선점을 알려주세요. 칭찬과 함께 구체적인 피드백을 제공하세요.` |

### 실험 설정
- **모델**: `gemini-2.5-flash` (오디오 입력 지원 ✅)
- **첨부**: 녹음 버튼으로 직접 녹음 또는 오디오 파일 첨부
- **텍스트 입력**: `(선택) 분석할 문장: "The quick brown fox jumps over the lazy dog."`

### 테스트 방법
1. 녹음 버튼 클릭 → 영어 문장 읽기 → 완료
2. 또는 오디오 파일(.mp3, .wav, .webm) 첨부
3. 실행하여 분석 결과 확인

## 3. 통합 테스트 파이프라인 🎧

**목적**: 녹음 → 분석 → 피드백 + 음성 생성

### 파이프라인 설정
- **이름**: `대화 연습 (통합)`
- **설명**: 발화 분석 후 음성 피드백 제공

### 에이전트 구성
| 순서 | 역할 | 프롬프트 |
|------|------|----------|
| 1 | 발음 분석가 | `학생의 오디오를 분석하고 발음과 억양에 대한 점수(1-10)와 의견을 작성해주세요.` |
| 2 | 영어 튜터 | `이전 분석을 바탕으로 학생에게 친절한 피드백을 제공하세요. 칭찬 → 개선점 → 연습 팁 순서로 영어로 답변하세요.` |

### 실험 설정
- **모델**: `gemini-2.5-flash`
- **데이터 전달 방식**: A (최종 출력만)
- **결과 음성 생성**: ✅ 체크
- **첨부**: 녹음 파일

### 테스트 흐름
```
녹음 → [에이전트1: 분석] → [에이전트2: 피드백] → 음성 TTS
```

## 모델별 기능 지원 표

| 모델 | 오디오 입력 | TTS | 권장 용도 |
|------|-------------|-----|-----------|
| `gemini-2.5-flash` | ✅ | ✅ | 범용 (추천) |
| `gemini-2.5-pro-preview-05-06` | ✅ | ✅ | 고품질 분석 |
| `gemini-2.5-flash-preview-tts` | ❌ | ✅ (전용) | 음성만 생성 |
| `gemini-3-flash-preview` | ❌ | ❌ | 텍스트 전용 |
| `gemini-3-pro-preview` | ❌ | ❌ | 텍스트 (고성능) |

---

## 참고
- 녹음 버튼은 **오디오 입력 지원 모델** 선택 시에만 표시됩니다.
- TTS 옵션은 **TTS 전용 모델 외** 모든 모델에서 사용 가능합니다.
