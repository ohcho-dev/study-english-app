# AI Agent Lab 완벽 가이드

> AI 파이프라인을 구성하고 테스트하는 실험 환경

---

## 📌 개요

AI Agent Lab은 여러 AI 에이전트를 파이프라인으로 연결하여 복잡한 작업을 수행하고, 다양한 AI 모델로 실험하며, 결과를 분석할 수 있는 어드민 도구입니다.

### 주요 기능

| 기능 | 설명 |
|------|------|
| 파이프라인 관리 | 에이전트 역할/프롬프트 정의 |
| 실험 테스트 | AI 모델 실행 및 테스트 |
| 에이전트별 모델 선택 | 각 에이전트에 다른 모델 지정 |
| TTS 음성 생성 | 최종 결과를 음성으로 변환 |
| 오디오 입력 | 녹음 또는 오디오 파일 분석 |
| 실험 로그 | 실행 결과 및 비용 추적 |

---

## 🚀 실행 방법

### 1. 서버 실행

```bash
cd apps/server
poetry run uvicorn app.main:app --reload
```

### 2. 어드민 실행

**기본 실행 (HTTP)**
```bash
pnpm start:admin
```

**HTTPS 실행 (녹음 기능 필요 시)**
```bash
pnpm start:admin:https
```

**네트워크 공유 (ngrok)**
> 같은 네트워크의 다른 기기에서 접속할 때 사용
```bash
# ngrok 설치 필요: brew install ngrok
pnpm start:admin:share
```

### 3. 접속

| 서비스 | URL |
|--------|-----|
| 어드민 대시보드 | http://localhost:3000 |
| 어드민 (HTTPS) | https://localhost:3000 |
| 어드민 (ngrok) | ngrok 콘솔에 표시된 URL |
| API 문서 | http://localhost:8000/docs |

## 📖 사용 방법

### 1️⃣ 파이프라인 생성

**경로**: AI Agent Lab → 파이프라인

1. `+ 파이프라인 생성` 클릭
2. 기본 정보 입력:
   - **이름**: 파이프라인 식별용
   - **설명**: 선택사항
   - **시스템 프롬프트**: 모든 에이전트에게 공통 적용되는 기본 지침
3. 에이전트 추가:
   - **역할**: 에이전트의 역할 이름
   - **프롬프트**: 해당 에이전트의 구체적 지시사항
   - 순서 변경: ↑↓ 버튼으로 실행 순서 조정
4. 저장

---

### 2️⃣ 실험 테스트 실행

**경로**: AI Agent Lab → 실험 테스트

1. **파이프라인 선택**
2. **AI 모델 선택** (기본 모델)
3. **데이터 전달 방식** 선택
   - `A`: 최종 출력만 전달
   - `B`: 전체 히스토리 전달
4. (선택) **에이전트별 모델 설정** 체크 → 각 에이전트에 다른 모델 지정
5. **사용자 입력** 작성 또는 **파일 첨부**
6. (선택) **TTS 음성 생성** 체크 → 음성 선택
7. `실험 실행` 클릭

---

### 3️⃣ 오디오 녹음 (마이크 입력)

> ⚠️ **HTTPS 필요**: `pnpm start:admin:https` 또는 `pnpm start:admin:share`로 실행

1. 오디오 입력 지원 모델 선택 (예: `gemini-2.5-flash`)
2. 🎤 버튼 클릭 → 녹음 시작
3. 녹음 완료 후 자동 업로드
4. 실험 실행

---

### 4️⃣ 실험 로그 확인

**경로**: AI Agent Lab → 실험 로그

- 전체 로그 목록 확인
- 상세 클릭 → 각 스텝별 입/출력, **사용된 모델**, 토큰 수 확인
- TTS 오디오 재생 가능

## 🧪 테스트 파이프라인 예시

---

### 파이프라인 1: TTS 테스트 🔊

**목적**: 텍스트 입력 → AI 응답 → 음성 생성

#### 파이프라인 설정

| 항목 | 값 |
|------|-----|
| **이름** | TTS 테스트 |
| **설명** | 텍스트 질문에 영어로 답변하고 음성으로 변환 |

#### 시스템 프롬프트

```
당신은 친근한 영어 선생님입니다.
학습자의 질문에 쉽고 명확한 영어로 답변합니다.
문법 설명이 필요할 경우 한국어로 간단히 보충합니다.
```

#### 에이전트 구성

| 순서 | 역할 | 프롬프트 |
|:----:|------|----------|
| 1 | 영어 선생님 | 학생의 영어 관련 질문에 친절하게 답변해주세요. 영어로 2-3문장으로 간결하게 설명하고, 필요시 예문을 포함해주세요. |

#### 실험 설정

| 항목 | 값 |
|------|-----|
| **모델** | gemini-2.5-flash |
| **데이터 전달 방식** | A (최종 출력만) |
| **결과 음성 생성** | ✅ 체크 |
| **음성** | Kore (여성) 또는 Puck (남성) |
| **파일 첨부** | 없음 |

#### 입력 예시

```
What's the difference between "affect" and "effect"?
```

#### 예상 결과

```
📝 텍스트 응답:
"Affect" is usually a verb meaning to influence something. 
For example: "The weather affects my mood."
"Effect" is usually a noun meaning a result. 
For example: "The medicine had a positive effect."

🔊 음성 응답:
위 텍스트를 TTS로 변환한 오디오 파일 생성
```

### 파이프라인 2: 오디오 입력 분석 🎙️

**목적**: 녹음 파일 → 음성 분석 → 피드백

> ⚠️ **HTTPS 필요**: 녹음 기능 사용 시 `pnpm start:admin:https` 또는 `pnpm start:admin:share`

#### 파이프라인 설정

| 항목 | 값 |
|------|-----|
| **이름** | 발화 분석 테스트 |
| **설명** | 학습자의 영어 발화 녹음을 분석하고 피드백 제공 |

#### 시스템 프롬프트

```
당신은 영어 발음 코치입니다.
학습자의 발화를 분석하여 건설적인 피드백을 제공합니다.
비판보다 격려를 우선하고, 구체적인 개선 방법을 제시합니다.
피드백은 한국어로 작성합니다.
```

#### 에이전트 구성

| 순서 | 역할 | 프롬프트 |
|:----:|------|----------|
| 1 | 발음 코치 | 학생이 녹음한 오디오를 분석해주세요. 다음 항목을 평가해주세요: 1) 발음 정확도 (1-10점) 2) 억양과 리듬 3) 유창성 4) 개선이 필요한 부분 5) 잘한 점. 마지막에 다음에 연습할 때 집중할 포인트 1가지를 제안해주세요. |

#### 실험 설정

| 항목 | 값 |
|------|-----|
| **모델** | gemini-2.5-flash (오디오 지원 ✅) |
| **데이터 전달 방식** | A (최종 출력만) |
| **결과 음성 생성** | ❌ 체크 안함 |
| **파일 첨부** | 🎤 녹음 버튼으로 직접 녹음 |

#### 입력 예시

```
분석할 문장: "The quick brown fox jumps over the lazy dog."
```

> 💡 녹음 방법: 🎤 버튼 클릭 → 위 문장을 영어로 읽기 → ⏹️ 정지 버튼 클릭

#### 예상 결과

```
📊 발화 분석 결과

✅ 잘한 점
- 전체적인 의미 전달이 잘 되었습니다!
- "quick"와 "brown"의 발음이 정확합니다.

📈 발음 점수: 7/10

💡 개선 포인트
1. "the" 발음: /ðə/에서 /ð/ 발음 주의 (혀를 치아 사이에)
2. "jumps" 끝의 /s/ 발음이 약합니다

🎯 다음 연습 포인트
"the"가 들어간 문장을 5번 읽어보세요:
"The dog, the cat, the bird"
```

### 파이프라인 3: 통합 테스트 🎧

**목적**: 녹음 → 분석 → 피드백 + 음성 생성 (멀티 에이전트)

> ⚠️ **HTTPS 필요**: 녹음 기능 사용 시 `pnpm start:admin:https` 또는 `pnpm start:admin:share`

#### 파이프라인 설정

| 항목 | 값 |
|------|-----|
| **이름** | 대화 연습 (통합) |
| **설명** | 발화 분석 후 음성 피드백 제공 (2단계 파이프라인) |

#### 시스템 프롬프트

```
당신은 영어 회화 코칭 팀입니다.
학습자의 발화를 분석하고 친절한 피드백을 제공합니다.
피드백은 항상 칭찬으로 시작하고, 구체적인 개선점을 제시합니다.
```

#### 에이전트 구성

| 순서 | 역할 | 프롬프트 |
|:----:|------|----------|
| 1 | 발음 분석가 | 학생의 오디오를 분석해주세요. JSON 형식으로 다음 정보를 작성해주세요: {"pronunciation_score": 1-10, "intonation": "평가", "fluency": "평가", "issues": ["문제점1", "문제점2"], "strengths": ["잘한점1"]} |
| 2 | 영어 튜터 | 이전 분석 결과를 바탕으로 학생에게 친절한 피드백을 **영어로** 제공해주세요. 구조: 1) 칭찬 (1문장) 2) 개선점 (1-2문장) 3) 연습 팁 (1문장). 총 4-5문장으로 작성해주세요. |

#### 실험 설정

| 항목 | 값 |
|------|-----|
| **모델** | gemini-2.5-flash |
| **데이터 전달 방식** | A (최종 출력만) |
| **에이전트별 모델 설정** | (선택) 에이전트 2에 gemini-3-pro-preview 사용 가능 |
| **결과 음성 생성** | ✅ 체크 |
| **음성** | Kore |
| **파일 첨부** | 🎤 녹음 버튼으로 직접 녹음 |

#### 입력 예시

```
연습 문장: "I'd like to order an iced americano, please."
```

> 💡 녹음 방법: 🎤 버튼 클릭 → 위 문장을 영어로 읽기 → ⏹️ 정지 버튼 클릭

#### 예상 결과

**에이전트 1 (발음 분석가) 출력:**
```json
{
  "pronunciation_score": 7,
  "intonation": "자연스러운 상승-하강 패턴",
  "fluency": "약간의 끊김이 있음",
  "issues": ["'iced'에서 /d/ 발음 누락", "'please' 끝 /z/ 발음 약함"],
  "strengths": ["'americano' 발음 정확", "전체적인 리듬감 좋음"]
}
```

**에이전트 2 (영어 튜터) 출력:**
```
Great job on pronouncing "americano" clearly! 
Your overall rhythm sounds quite natural.
Try to emphasize the "d" sound at the end of "iced"—say "ice-duh" quickly.
Practice this phrase slowly first, then speed up: "iced, iced, iced americano."
```

**TTS 음성:**
```
위 영어 튜터 응답을 Kore 음성으로 변환한 오디오 생성
```

## 🔬 영어 서비스 실험 예시

### 실험 1: 시나리오 콘텐츠 생성

**목적**: 다양한 상황의 영어 회화 시나리오를 AI로 자동 생성

**파이프라인 구성**:

| 순서 | 역할 | 프롬프트 요약 |
|:----:|------|-------------|
| 1 | 상황 리서처 | 상황별 대화 시나리오 3가지 버전 조사 (난이도별) |
| 2 | 대화 작성자 | 완전한 대화 스크립트 작성 (발음 가이드 포함) |
| 3 | 표현 분석가 | 핵심 표현 5개 추출 및 분석 |
| 4 | 품질 검수자 | 문법, 자연스러움, 문화적 적절성 검토 |

**입력 예시**:
```
상황: 공항 체크인 카운터
레벨: 중급
특수 상황: 수화물이 무게 초과되어 추가 요금을 내야 하는 상황
```

미션: 아이스 아메리카노 주문하기

## ❓ FAQ

**Q: 실험 결과가 저장되나요?**
A: 네, 모든 실험 결과는 DB에 자동 저장되며 "실험 로그" 페이지에서 확인할 수 있습니다.

**Q: 에이전트는 몇 개까지 추가할 수 있나요?**
A: 제한 없이 추가 가능하지만, 3-5개를 권장합니다.

**Q: 파일 첨부는 어떤 형식을 지원하나요?**
A: 이미지(jpg, png, gif, webp), 비디오(mp4, webm), 오디오(mp3, wav, webm) 파일을 지원합니다.
