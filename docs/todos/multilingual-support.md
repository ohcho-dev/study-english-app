# 다국어 지원 (Multilingual Support) - 보류됨

## 개요
현재 Google Cloud TTS를 사용 중이나, 한국어/영어가 혼용된 문장을 자연스럽게 발음하지 못하는 한계가 있음.
OpenAI TTS 도입을 검토했으나 비용/크레딧 문제로 보류됨.

## 목표
- 한국어와 영어가 섞인 문장(예: "Hello 여러분")을 자연스럽게 발음하는 TTS 도입.

## 검토된 대안

### 1. OpenAI TTS
- **장점**: 별도 설정 없이 다국어 혼용 발음이 매우 자연스러움.
- **단점**: 비용 발생 (Google Cloud 무료 크레딧 활용 불가).

### 2. ElevenLabs
- **장점**: 품질 최상.
- **단점**: 비용 높음.

### 3. Google Cloud TTS (Audio Stitching)
- **방식**: 문장을 언어별로 쪼개서 각각 다른 보이스로 생성 후 합침.
- **장점**: 무료 크레딧 활용 가능.
- **단점**: 구현 복잡도 높음, 문장 중간 어색함, 레이턴시 증가.

## 추후 계획
- Google Cloud 무료 크레딧 소진 후 혹은 고품질 TTS가 반드시 필요한 시점에 OpenAI 도입 재검토.
- 또는 Google의 Polyglot 기능이 한국어를 지원하게 되면 재검토.
