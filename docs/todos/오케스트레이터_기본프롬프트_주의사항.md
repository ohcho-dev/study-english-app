# 오케스트레이터 Base Prompt 주의사항

> 파일: `apps/server/app/services/conversation/scenario_director.py`

## 현재 Base Prompt에서 주의할 항목

### 1. PASS = "coherent English" (L90)
```
ONLY use PASS when: The input is coherent English.
```
- **현재**: 영어 학습 앱이므로 적합
- **향후 위험**: 다국어 대화 템플릿 (예: 한일 언어교환) 생성 시, 한국어 입력이 절대 PASS가 안 됨
- **해결**: 필요 시 `"coherent English"` → `"coherent response"` 로 변경하거나, 커스텀 Director 프롬프트에서 오버라이드

### 2. FAIL = "Mistranscribed foreign language" (L79)
```
Mistranscribed foreign language → FAIL
```
- **현재**: STT에 `alternativeLanguageCodes: ["ko-KR"]` 추가되어 한국어가 정상 인식됨
- **향후 위험**: 정상 인식된 한국어도 "외국어 오인식"으로 FAIL 처리 가능
- **해결**: Director LLM이 문맥을 보고 판단하므로 실제 오탐 확률 낮음. 그러나 명시적으로 수정하려면 해당 예시를 제거하거나 "unintelligible foreign text"로 변경

## 권장 패턴: 템플릿별 커스텀 Director 프롬프트 활용

Base Prompt는 **범용적**으로 유지하고, 템플릿별 특수 규칙은 **커스텀 Director 프롬프트**에 작성:

```
# 예시: 한국어 튜터가 있는 템플릿
BRIDGE SPEAKER:
- When the user speaks Korean, hesitates, or asks for help:
  set bridge_speaker to "수진쌤".
- For ALL non-PASS evaluations, set bridge_speaker to "수진쌤".
```

```
# 예시: 한국어 허용 템플릿 (언어교환)
Korean input should be evaluated as PASS if contextually relevant.
```
