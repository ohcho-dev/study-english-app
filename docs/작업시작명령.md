## 6단계: Phase 2/3 작업 유의사항 (중요)

1. **페이지 분리**: 
   - 기존의 `run0` 페이지(**Latency Lab**)는 **레이턴시 및 베이스라인 측정용**으로 그대로 유지해야 함.
   - Phase 2(WebRTC) 기능은 반드시 **새로운 페이지(예: `/conversations/my-turn`)**를 생성하여 구현할 것.
   - `docs/plan/my-turn-master-plan.md`의 **4.5 UI/UX 전략** 및 **7.3 상세 서버 로직** 참고.
   - 특히 **WebRTC Signaling** 및 **Turn Orchestrator** 구현 시 7.3절의 명세를 준수할 것.

2. **템플릿 재사용**:
   - `ConversationTemplate` 모델은 공통으로 사용하되, 실행 모드(Run0 vs My Turn)에 따라 동작이 달라지도록 구현.
   - 템플릿 상세/편집 화면에 **My Turn 전용 필드(턴 모드 등)**를 추가하여 확장할 것.

3. **개발 주의사항**:
   - 정해진 개발 아키텍처, 코딩 규칙, 라이브러리 가이드, 개발 프로세스를 준수할 것.
   - 터미널 명령어가 필요한 경우 클라이언트에게 요청할 것.
   - 새로운 기능을 추가하는 경우, 기존 기능에 영향을 주지 않도록 주의할 것.
   - db, server, admin을 모두 고려해가면서 사고하고 개발할 것
   - db 마이그레이션이 필요한 경우 마이그레이션 파일을 생성하고, 터미널 명령어 실행을 클라이언트에게 요청할 것
